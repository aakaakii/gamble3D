# 神秘3d抽奖程序！

## data.txt

data.txt 中包含所有参与抽奖成员的名称。用空白字符（换行/空格）分隔。这意味着名字中不能含有空格。

不需要显式指定数量，参考给出的格式。

## settings.txt

包含一些可选配置。默认的是视觉效果较好的。需要较快/较慢节奏也可以自行修改。

第一行包含两个整数 L, R，表示一次出局的人数的范围。实际的数会在这个范围内每次随机。建议 $1\le L\le R\le 5$。

第二行包含一个整数，表示中奖人数，也就是最终剩下的人数。

第三行包含三个参数 $t_1, t_2, v_0$。$t_1$ 表示加速阶段的时长。$t_2$ 表示减速阶段的时长。通过控制这两项可以控制整体节奏。$v_0$ 表示目标速度。运行时将会用 $t_1$ 秒 加速至 $v_0$，然后在 $t_2$ 秒内减速到 $0$。

第四行包含两个整数，表示程序窗口宽度和高度。
